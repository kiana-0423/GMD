# 算子与物理契约

数学来源：预印本中的 Gather/伴随装配、二体/EAM 重构、邻居有效性、
Velocity Verlet、实现语义及维里附录。本文件将其转成实现验收条件。

## 1. 单位与方向

沿用 GMD 的物理单位约定：长度 Å、能量 eV、质量 amu、电荷基本电荷、温度 K。
积分内部时间为 `Å * sqrt(amu/eV)`，外部 fs 在输入输出边界转换。
P0 仅验证一致单位下的静态算子。P1.1 在 `core/units.hpp` 独立定义 fs↔内部
时间、eV/Å³↔bar 换算及 k_B，注明 SI/CODATA 来源，数值与旧引擎常数一致但
不包含旧头文件；reduced 单位没有换算尺度，换算到 fs/bar 时报错。温度计算
尚未实现。

对半表边 `e=(i,j)`：

```text
d_e = x_j - x_i - H^T lambda_e
g_e = phi'(r_e) d_e / r_e
F_i += g_e, F_j -= g_e
U = sum_e phi(r_e)
W_ab = -sum_e d_e[a] g_e[b]
```

晶格矢量为矩阵的行；矩阵表达为 `D = B X - Lambda H`。
`W` 按行存储九个分量。与旧 LJ 的 `x_i-x_j` 对照时同时映射导数符号。
对称全表若只向源原子收集力，能量和维里乘 `1/2`，源原子力不乘 `1/2`。
只有完整双向关系、对称模型和相反镜像分支才可使用该等价式。

## 2. 算子表

| 算子 | 输入 → 输出 | 必须保持的契约 |
|---|---|---|
| Gather | `X[N,3], I[P,k] → Q[P,k,3]` | 有序角色不变；索引在范围内 |
| AssembleSum | `Z[P,k,3], I → F[N,3]` | 重复索引求和；与 Gather 伴随；声明覆盖/累加模式 |
| Difference | `X, I, H, Lambda → D[P,3]` | 当前镜像；固定分支求导；不永久缓存旧位移 |
| LocalMap | 局部几何/参数 → 能量与局部导数 | 解析导数或雅可比转置作用；退化输入有明确定义 |
| SegmentSum | `values, segments → node values` | 空段为零；分组排序与置换保持一致 |
| ReduceSum | 局部能量/维里 → 总量 | 明确 owned/global 范围、精度及归约策略 |
| NeighborRelation | 状态、半径、容量 → 候选索引/有效性 | 覆盖所有活跃关系；溢出显式失败 |
| StateUpdate | 当前状态、力、步长 → 新状态 | 保留 Verlet 阶段和力对应的坐标版本 |
| Solve（后续） | 约束/场的耦合问题 → 解及收敛状态 | 不以独立 Map 替代耦合求解；失败不得提交时间步 |

多输入分支的反向贡献也必须求和。数学中间张量不要求物化；融合后的输出
仍要与这些契约一致。禁止为实现图公式构造生产规模的稠密关联矩阵。

## 3. 模型与拓扑

- 半表每个无序对出现一次；自边和重复无序边应被拒绝。
- `potential_shift`：`u=phi(r)-phi(rc)`，力仍为原始力，`r>=rc` 时均为零。
- `force_shift`：再减 `(r-rc) phi'(rc)`，径向导数减 `phi'(rc)`。
  两者是不同模型，不得因 GPU 适配自动切换。旧 GMD LJ 对照使用前者。
- 排除、1–4 缩放、混合规则及显式类型对参数属于模型输入。
  P0 仅支持统一 epsilon/sigma 和逐边非负缩放，不支持完整类型表。
- bonded 的有序索引和镜像与非键邻居表分别管理；非键 cutoff 不删除键。
- EAM 必须完成密度归约，再计算嵌入导数并传回边端。多元素密度贡献
  `psi_receiver<-contributor` 可以不对称，不能只保存一个对称标量。

## 4. 周期与邻居有效性

首个生产切片限定固定正交盒与最近镜像模型，要求
`r_list = rc + skin < min(periodic lengths)/2`。无周期维度不做折回。
维护能处理跨盒移动的连续位移/像计数，以 `2*dmax < skin` 作为重用充分条件。
盒、排列、分区、模型 cutoff 或拓扑变化也可能使缓存失效。

候选列表复用不代表镜像整数可永久复用。半盒简并点需要一致的端点方向
规则；多设备的反向边必须采用相反分支。一般倾斜盒不能直接用分数坐标
逐分量 round 充当通用最近晶格点算法。

P0 的可选正交盒仅检验静态最近镜像：必须使用有限 cutoff，且 cutoff
小于周期边长一半。P0 不构建邻居表，其显式半表的完整性由调用方保证。

## 5. 错误、容量和数值

空关系返回零输出。非法索引、重复对、自边、非有限参数及活跃的重合粒子
显式失败。排除边在奇异运算前跳过；未来 padding 必须在读取无效索引或
计算 `1/r` 前判断，不允许 `0 * infinity` 掩盖错误。

邻居容量溢出时结果无效：报告所需容量、扩容、重建、重算；禁止截断边。
GPU 工作提交后需合并 kernel/库错误与设备状态，再标记结果可消费。

基线为 FP64。普通模式允许容差内差异；确定性模式必须固定有效范围内的
分组和归约顺序，并说明保证所依赖的 GPU、工具链与配置。不得把普通
`atomicAdd` 或 CUB 调用解释为跨设备逐位一致保证。

长程静电、约束、外场、显式盒依赖和 NPT 维里不自动继承短程二体公式。
